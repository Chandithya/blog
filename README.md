# N Chandithya — Personal Blog

A responsive personal website styled to match the supplied pink scrapbook-style reference: deep rose headings, pink cards, a compact dashboard layout, photo gallery, and mobile navigation.

## Run in VS Code
1. Extract the ZIP file.
2. Open this folder in Visual Studio Code.
3. Open `index.html` using Live Server (recommended) or your browser.

## Files
- `index.html` — website content
- `style.css` — pink design and responsive layout
- `script.js` — navigation, theme toggle and reading progress

The pink theme is the default. The theme button can switch to a dark rose version. Google Fonts and decorative Unsplash photos need an internet connection.
